API reference
=============

The pipeline runs three classes in order: :class:`~vorflow.ConceptualMesh`
collects and cleans the features, :class:`~vorflow.MeshGenerator` meshes them
with Gmsh, and :class:`~vorflow.VoronoiTessellator` builds the Voronoi grid.

Hybrid triangle subregions
--------------------------

``ConceptualMesh.add_polygon(..., resolution=h, subregion="triangle")``
registers one reservation independently of geological zones (omit ``zone_id``).
Its perimeter is generated by the ordinary exact-circle barrier planner.
``VoronoiTessellator.generate()`` removes only complete interior Voronoi cells
and fills that same footprint with retained triangles. It refuses material
perimeter crossings and barrier fallback repairs.

The resulting grid has ``cell_type`` (``voronoi`` or ``triangle``),
``generator_origin``, ``source_node_id`` and ``source_element_id`` metadata.
These columns also appear in MFUSG ``cell_map`` output. Retained Voronoi
generators and node IDs are unchanged; triangle IDs do not reuse removed IDs.

``construction_grid`` exposes the first-pass cells; ``exterior_grid`` exposes
the complete retained cells before triangulation. ``hybrid_report`` records
removed IDs, coverage error and zero hybrid clip area.
``requested_triangle_footprint`` and ``realised_triangle_footprint`` show the
fixed interface. The first construction pass currently meshes both sides.
Embedded interior points and non-barrier lines are unsupported, and all fault
lines must fit inside the reservation. No hydraulic resistance is assigned.
